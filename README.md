# api_final

## Как запустить проект:

Создать и активировать виртуальное окружение:

```
python -m venv venv
```

```
source venv/Scripts/activate
```

Установить зависимости:

```
python -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python manage.py migrate
```

Запустить проект:

```
python manage.py runserver
```

## Описание проекта:

Проект `API для Yatube` - это backend-часть платформы для размещения пользовательских публикаций. 

Авторизованный пользователь может:
- Просматривать список всех публикаций, задавая параметры пагинации `limit` и `offset`;
- Просматривать конкретную публикацию;
- Создавать, частично или полностью изменять, удалять свою публикацию;
- Просматривать все комментарии или отдельный комментарий;
- Создавать, частично или полностью изменять, удалять свой комментарий;
- Получать список сообществ или информацию о конкретном сообществе;
- Подписываться на других пользователей, получать информацию о своих подписках.

Анонимный пользователь может:
- Просматривать список всех публикаций, задавая параметры пагинации `limit` и `offset`;
- Просматривать конкретную публикацию;
- Просматривать все комментарии или отдельный комментарий;
- Получать список сообществ или информацию о конкретном сообществе.

## Примеры запросов к API:

Получение публикаций: GET `api/v1/posts/`

Создание публикации: POST `api/v1/posts/`
Пример запроса:

```
{
  "text": "string",
  "image": "string",
  "group": 0
}
```

Получение публикации: GET `api/v1/posts/{id}/`

Обновление публикации: PUT `api/v1/posts/{id}/`
Пример запроса:

```
{
  "text": "string",
  "image": "string",
  "group": 0
}
```

Частичное обновление публикации: PATCH `api/v1/posts/{id}/`
Пример запроса:

```
{
  "text": "string",
  "image": "string",
  "group": 0
}
```

Удаление публикации: DELETE `api/v1/posts/{id}/`

Получение комментариев: GET `api/v1/posts/{post_id}/comments/`

Добавление комментария: POST `api/v1/posts/{post_id}/comments/`
Пример запроса:

```
{
  "text": "string"
}
```

Получение комментария: GET `api/v1/posts/{post_id}/comments/{id}/`

Обновление комментария: PUT `api/v1/posts/{post_id}/comments/{id}/`
Пример запроса:

```
{
  "text": "string"
}
```

Частичное обновление комментария: PATCH `api/v1/posts/{post_id}/comments/{id}/`
Пример запроса:

```
{
  "text": "string"
}
```

Удаление комментария: DELETE `api/v1/posts/{post_id}/comments/{id}/`

Список сообществ: GET `api/v1/groups/`

Информация о сообществе: GET `api/v1/groups/{id}/`

Подписки: GET `api/v1/follow/`

Подписка: POST `api/v1/follow/`
Пример запроса:

```
{
  "following": "string"
}
```

Получить JWT-токен: POST `api/v1/jwt/create/`
Пример запроса:

```
{
  "username": "string",
  "password": "string"
}
```

Обновить JWT-токен: POST `api/v1/jwt/refresh/`
Пример запроса:

```
{
  "refresh": "string"
}
```

Проверить JWT-токен: POST `api/v1/jwt/verify/`
Пример запроса:

```
{
  "token": "string"
}
```
